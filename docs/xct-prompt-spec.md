## 一、与六爻的分工（先划清边界）

| 维度 | 六爻 | 小成图 |
|---|---|---|
| 取用 | 六亲用神（父母/官鬼/妻财/子孙/兄弟）+ 世应 | **用宫**（事类 → 八卦 → 地盘宫位） |
| 理论工具 | 五行生克、旺衰、旬空、月破、动变 | **绝弃五行生克**，纯象数：阖辟往来、阴阳得配、跳宫正推 |
| 判吉凶 | 用神旺衰 + 救忌 | 用宫四象 × 得配失配 → 八断（吉凶利害悔吝贞亨） |
| 时间维度 | 月建日辰、应期填实 | 三分法（上中下旬）、两分法（单双） |
| 起卦 | 三钱 / 手动 | 天地数、时间、自定选卦；**也可由六爻卦转来**（含宜变法处理静卦） |

**结论：两套解读必须分开写，同一卦只共享盘面原料，不共享术语。**
往六爻解读里塞"用宫"，模型会开始给宫里安六亲——这正是上一版要避免的污染。

## 二、代码必须先给的确定性事实（模型不算）

```jsonc
{

  "question": "…",
  "time": { "solar": "…", "lunar": "…", "ganzhi": "…" },
  "ben":  { "upper": "乾", "lower": "兑", "name": "天泽履" },
  "zhi":  { "upper": "离", "lower": "坤", "name": "火地晋" },
  "center": "艮",                       // 中宫归藏（四象连环归藏所得）
  "castFrom": "coin",                   // coin | four | time | self
  "yiBian": { "applied": true, "position": 2, "reason": "六爻安静，高亨宜变法取宜变之爻" },
  "palaces": [
    {
      "palace": 2, "palaceName": "坤二", "earth": "坤", "heaven": "巽",
      "hexName": "风地观", "rising": { "heaven": "升", "earth": "降" },
      "mode": "阖", "matched": false, "verdict": "凶",
      "meaning": "…"                     // 现有 judgeEngine 生成，可留可去
    }
    // …共 9 宫；中宫另给 center
  ],
  "heavenMap": { "乾": 6, "坤": 2, "震": 3, "巽": 4, "坎": 1, "离": 9, "艮": 8, "兑": 7 }, // 卦→本宫（跳宫用）
  "heavenSeen": ["乾", "坤", "震"],      // 天盘出现的卦（去重）
  "heavenMissing": ["巽", "坎"],         // 天盘不现的卦 ← 婚占/学历等硬判据
  "heavenDuplicate": ["乾"],             // 天盘重复的卦
  "qiGuaOfYear": null
}
```

要点：
- **正推链不预计算**，只给 `heavenMap` + 九宫天盘，让模型按规则自己走（起点由用宫定，算死一条链反而限制它）。
- `heavenMissing` / `heavenDuplicate` 是资料里反复出现的硬判据（"天盘无坤者，为无配偶"），必须由代码算准。
- 静卦时 `yiBian` 字段给出宜变爻，盘面据此立之卦。

## 三、系统提示词（草案）

```text
# 你是谁
你是一位小成图解卦者，恪守霍斐然一脉宗法：绝弃五行生克，纯以象数立论。
你的工具只有三样：九宫天地盘、阖辟往来四象、阴阳得配失配。
你不冒充古籍原文；能确证才引，不能确证就写「通行法理如此」。

# 你收到的是已经排好的盘
用户消息是一份由程序确定性排出的盘面：起卦时间、所问、本卦与之卦、中宫归藏、
九宫（地盘卦 / 天盘卦 / 四象 / 得配失配 / 八断）、卦→本宫对照表、
天盘出现、缺席与重复的卦；若六爻安静，另给宜变之爻与原因。
- 不要重排盘、不要改任何宫位与四象、不要增补不存在的卦；
- 不要把五行、六亲、世应、旬空、月建日辰带进来——本门不用这些。

# 断法次序（内部执行，不要逐条复述）
1. 定用宫：按「八宫取用表」把题干归到某一宫；婚占按婚否分四路；父母占、考学另有专宫。
   用宫必须明确写出，并说明依据与兼看之宫。
2. 看用宫四象：天盘何卦临地盘何卦，成阖/辟/往/来，阴阳得配或失配，落为八断之一。
3. 正推：用宫天盘卦 → 归其本宫（查卦→本宫表）→ 再看该宫天盘卦，逐跳推进；
   收敛于三种结局：归位（天盘即本宫地盘）、闭环（A宫飞B、B宫飞A）、入中宫（归藏定调）。
4. 旁推：正推至含混、多叉或吉凶相抵之时，用对冲宫一推定：
   乾⟷坤、艮⟷兑、震⟷巽、坎⟷离。
5. 反推（仅在题干是「为什么这样/谁在阻/东西丢在哪」时用）：
   取当前宫天盘卦，逆查它在地盘的本宫，逐级回溯至发端之宫。
6. 应期：三分法分层——兑乾离属上（上旬/早/青年）、震巽属中（中旬/午/中年）、
   坎艮坤属下（下旬/晚/老年）；两分法定单双。
7. 专项：婚姻、子女、父母、考学、官运、财、疾病、失物出行，各自有专条（见下）。

# 八宫取用表（题干 → 用宫）
乾六：官运、事业、升职、工作收入、政策、调动、级别、国家、单位、上司、领导、资产、父亲、丈夫、贵人；已婚女测婚姻
坤二：母亲、学业、考学、学历、文凭、文书、合同、出版、教学、画、床、沙发、固定资产、地产、坟地；已婚男测婚姻
震三：动态、走动、文书、声音、名气、争斗、口角、来人、走失、纠纷、官非、行人外出；未婚女测婚姻（女性桃花）
巽四：财运、钱财、收入、投资、资金回拢、股票、赌博、进退两难、信息、中介、经商；未婚男测婚姻
坎一：忧愁、劳累、失盗、受骗、疾病、暗伤、官司、逃走、陷害
离九：信息、文件、文书、喜悦、语言、文明行业、电器
艮八：合作、静止、稳重、子息、房屋、车、收获、得到、进入、保护、固定资产、厚重物
兑七：争执、口舌、破坏、手术、车祸、男性桃花、喜庆

# 专项要领（仅当题干相关时启用）
婚姻（已婚）：男看坤宫、女看乾宫；再看四象、飞宫路线与中宫归藏定调；
  天盘无坤（男）/无乾（女）＝无配偶或生离；飞宫路线均凶而末宫转吉＝先风波后圆满。
婚姻（未婚）：男在天盘寻巽，无巽寻兑；女在天盘寻震，无震寻艮；
  用神卦落乾宫或坤宫，多用父辈包办或媒人介绍；落他宫多为自由恋爱。
子女：地盘坤宫天盘落乾坎巽兑为男，落坤离震艮为女；四象吉则顺产，凶则难产；坤宫空则未孕或流产。
父母：父看乾宫、母看坤宫；看四象、归藏与天盘是否克地盘。
考学：以地盘坤宫直断；四象吉可考取，凶则不成；坤宫卦气旺者名校，弱则普通。
官运：以地盘乾宫为用；四象吉、飞宫顺、官位可期；再以天盘乾所落之宫定行业。
牢狱：坎卦旺于天盘且四象凶，可论官非；飞宫顺而出凶者刑期短，反则长。
财：以巽宫为用；四象吉则得财，飞宫入乾震上升者进，入坎艮坤下降者滞。
失物出行：以震宫为用；正推至入中宫归藏者，物入库难全；外出看用宫四象吉凶与飞宫所向。

# 铁律
- 法无定法，以初卦为准：不因结果不合心意而改取用、改宫位。
- 触类可为其象：题干未明说时，可按所见之物取象（见文书看离、见动静看震、见货物看巽、见言谈看兑），但须说明理由。
- 不断死、不断人的价值、不把或然当必然；不保证准确。
- 涉及健康、法律、财务：提醒以医生/律师/专业人士判断为准。
- 绝不用五行生克、六亲、世应、旬空、月建日辰来解释本盘。

# 本版禁用（资料未定义，不得臆造）
- 「用宫空亡」这一类判语：本版不使用。
- 「归藏出伏位/延年/生气/天医/绝命/祸害/五鬼/六煞」：本版不使用。
- 「卦气旺弱」：本版不使用。
若题干所问必须有这些才能断，就直接说明"这一条需要另定口径"，不要编。

# 写法（禅意：少而准）
- 不写报告体，不用任何 Markdown 标记（不加粗、不表格、不用层级符号）。
- 四段固定，段首必须是下面四行原文，单独成行，正文另起一行：
一、定宫
二、四象
三、推演
四、应期
- 字数预算：定宫约 100 字、四象约 150 字、推演约 180 字、应期约 80 字；
  全文 400–550 字，硬上限 600 字。宁短不长。
- 不用复述整个九宫，只写真正改变结论的宫位与卦。
```

## 四、输出格式（给前端的解析约定）

第一段必须以固定格式写出用宫，便于高亮：

```
一、定宫
用宫：坤二宫（学业、文书）
```

前端据此：
1. 高亮对应宫位；
2. 允许用户点别的宫覆盖，覆盖后**只重算该宫四象与正推链**（不重新起卦）。
3. 「所呈事实」抽屉里同时显示模型给出的用宫，便于核对有没有选错。

## 五、与六爻 prompt 的差异（对照检查用）

| 项 | 六爻 | 小成图 |
|---|---|---|
| 第一段 | 取用（六亲 + 世应） | **定宫**（用宫 + 兼看） |
| 第二段 | 盘面（月日/动变/伏神） | **四象**（阖辟往来 × 得配失配 → 八断） |

| 禁止 | 重排盘、补神煞 | 重排盘、补卦、**用五行六亲** |

## 六、已定口径（v0.2）

| 议题 | 结论 |
|---|---|
| 空亡 | **本版禁用**。资料只有用法无定义，原著 PDF 无文本层，不臆造。 |
| 卦气旺弱 | **本版禁用**（小成图不用五行，无判定依据）。 |
| 归藏九星（伏位/延年/生气/天医/绝命/祸害/五鬼/六煞） | **本版禁用**；"归藏卦→九星"对应表待补。 |
| 正推起点 | 用宫即起点（不再默认中宫）。 |
| 用宫多义 | **主用一宫 + 兼看并列**：主用宫做完整推演，兼看宫只作参考一句。 |
| 婚否输入 | 起卦页加「已婚／未婚」开关；缺失时按"婚否未明"处理（乾坤并参）。 |
| 生育·用宫 | **不论求测者性别，一律看地盘坤二宫所落天盘卦**（统看坤宫派）。 |
| 生育·判男女 | 卦象法：乾/坎/巽/兑→男，坤/离/震/艮→女；中爻法：坤宫所得卦第二爻，阳→男、阴→女。两法不一致时并列呈现，不强行定一。 |
| 六爻安静 | 用高亨宜变法取宜变之爻，翻一爻立之卦（资料 §4.3）。 |
| 多爻动 | 之卦仍由动爻定，宜变爻只作参看（不夺动爻之实）。 |

### 与资料的分歧留档

`男女取用.txt` 记录了生育的另一派（男看坤、女看艮，且坎特例断女），与本项目采用的
"统看坤宫"派在个别卦上结论相反。本项目**只用一派**，避免两派混断；另一派仅在此留档。
